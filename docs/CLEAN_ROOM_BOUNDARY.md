# Clean-room boundary

RiskHarbor is a new implementation of general insurance-administration
workflows. Historical archives were used only to identify broad business
capabilities. No historical source code, database rows, organization names,
screens, credentials, rates, filing layouts, or proprietary terminology are
included.

All examples are synthetic. Classification codes, policy numbers, people,
organizations, amounts, dates, and decisions in tests are fictional.

Regulatory EDI is excluded until an adapter can be implemented from current,
authoritative specifications under appropriate access terms. Old layouts are
not treated as specifications.
